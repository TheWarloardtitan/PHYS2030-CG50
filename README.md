# PHYS2030 for Casio fx-CG50
No WSL or virtualization changes are required. Upload this whole project to GitHub, run the included GitHub Actions workflow, and download the PHYS2030-CG50 artifact. It will contain PHYS2030.g3a.

This first hardware-test build contains the menu, formula library, a worked kinematics example, and scaffolds for the remaining planned modules. It intentionally proves the build/install pipeline before the full solver is expanded.
